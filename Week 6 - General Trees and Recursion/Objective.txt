Objective:

• Practice representing hierarchical data using a general tree structure

• Apply recursion to traverse a tree using depth-first search (DFS)

• Connect tree concepts to a real-world file system model using Node.js filesystem access

• Gain hands-on experience implementing and testing recursive tree operations

Instructions:

1. Create a class named FileNode that represents a file or folder

2. Include fields for:

   • the file or folder name
   • the node type (file or folder)
   • a list of child nodes

3. Use the Node.js fs module to access a real folder structure on your local machine

4. Implement an addChild method that adds a child node to the current node

5. Implement a recursive method that scans directories, reads files and folders, and builds a tree structure dynamically from the filesystem

6. Implement a print method that displays the tree using indentation to show hierarchy

7. Implement a find method that searches for a node by name using depth-first search (DFS)

8. Extend your program with a simple command-line interface (CLI)

9. The CLI should allow the user to:

   * choose or define a starting directory
   * scan folders and files
   * print the full tree structure
   * search for files or folders by name

10. Test your program by creating or selecting a folder structure with at least two levels of nested folders/files

11. Avoid scanning the entire root directory of your operating system. Instead, use a smaller directory such as a projects, documents, downloads, or test folder.
